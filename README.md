# popnei

Population genetics in Rust, used from Python, natively and in the
browser under pyodide, and from TypeScript in web applications, compiled
directly to WebAssembly. The successor of [pyNei](https://github.com/JoseBlanca/pynei),
named after Masatoshi Nei.

The objectives are in `docs/objectives.md`, and the design decisions with
the measurements behind them in `docs/rust_core.md`.
